# Нейросетевое моделирование результатов выборов президента Российской Федерации

Учебное ретроспективное исследование официально опубликованных итогов выборов за 1996–2024 годы. Результаты модели не предназначены для прогнозирования будущих кампаний.

## Данные
- `data/raw/` — исходные результаты, даты рождения, сведения о должностях и источники.
- `data/processed/candidates.csv` — 48 наблюдений (33 кандидата), признаки и ссылки.
- `data/processed/train.csv` — 36 наблюдений, кампании 1996–2012.
- `data/processed/validation.csv` — 8 наблюдений, 2018.
- `data/processed/test.csv` — 4 наблюдения, 2024.
- `data/results/` — результаты шести запусков, исторического тестирования и 16 сценарных вычислений.

X1 — возраст в полных годах; X2 — действующий президент РФ или и. о.; X3 — количество предыдущих фактических участий начиная с 1996 года; X4 — ранее занимаемая высшая государственная должность из согласованного перечня, включая исторические аналоги СССР и РСФСР. D1 — официальная доля голосов, %.

## Воспроизведение
1. Запустить `python scripts/prepare_dataset.py` (Python 3, без внешних зависимостей).
2. Открыть Нейросимулятор 5. Четыре линейных входа, один линейный выход, гиперболический тангенс в скрытом слое. Сравнить 4–1, 4–1–1, 4–2–1 и 4–3–1.
3. Загрузить train и validation в верхнюю и нижнюю таблицы обучения соответственно (при необходимости преобразовать CSV в XLSX).
4. Обучение: Rprop, автоматическая инициализация, линейное масштабирование от −1 до 1, 200 итераций. Случайные начальные веса могут дать другие результаты.
5. Для исторической проверки используется сохранённый проект первого запуска 4–1–1. Не переобучать его на тестовых данных.
6. Запустить `python scripts/evaluate_results.py`, чтобы проверить метрики по сохранённым результатам.

## Результаты и ограничения
Минимальная наблюдаемая ошибка валидации по показателю Нейросимулятора: 6,82871 (4–1–1, первый запуск). Повторные запуски не подтвердили устойчивость результата. MAE на данных 2024 года — 30,47 п. п., RMSE — 40,86 п. п. Константная оценка по среднему D1 обучающей выборки показала соответственно 25,75 и 37,83 п. п. Поэтому модель не рекомендуется для практического прогнозирования. Сценарные вычисления характеризуют только математическую модель и не доказывают причинное влияние факторов. Значимость параметров в отчёте оценена приближённо по диаграмме программы.

Проекты Нейросимулятора в формате .np4 следует разместить в папке models/. Отчёт содержит графики и скриншоты.
